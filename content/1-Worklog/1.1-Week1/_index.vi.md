### Mục tiêu tuần 1:

* Làm quen với môi trường học tập của First Cloud AI Journey (FCAJ) và lộ trình học tập về AWS.

* Nắm được các kiến thức cơ bản về AWS, bao gồm các nhóm dịch vụ cloud chính, quản lý tài khoản, quản lý chi phí, quản lý danh tính và quyền truy cập, networking và compute.

* Có kinh nghiệm thực hành với các dịch vụ AWS cơ bản và quản lý tài nguyên trên môi trường cloud.

* Phát triển kỹ năng cơ bản trong việc triển khai, kết nối và xử lý sự cố đối với các tài nguyên AWS.

* Ôn tập các dịch vụ và khái niệm AWS sẽ làm nền tảng cho workshop/project trong thời gian thực tập.

### Kết quả đạt được trong tuần 1:

* Nắm được kiến thức nền tảng về AWS và các nhóm dịch vụ chính.

* Làm quen với AWS Management Console và tổng quan về lộ trình học tập AWS Cloud Journey.

* Tìm hiểu các kiến thức cơ bản về quản lý tài khoản và chi phí AWS, bao gồm:

  * AWS Free Tier
  * AWS credits
  * AWS Budgets
  * Theo dõi chi phí cơ bản

* Nắm được các kiến thức cơ bản về AWS Identity and Access Management (IAM), bao gồm:

  * IAM User
  * IAM Group
  * IAM Policy
  * IAM Role
  * Quản lý permissions
  * Role assumption
  * Switch Role

* Thực hành tạo và quản lý IAM User, Group, Policy và Role.

* Tìm hiểu các thành phần cơ bản của AWS Networking, bao gồm:

  * Amazon VPC
  * Subnet
  * Route Table
  * Internet Gateway
  * NAT Gateway
  * Security Group
  * Network ACL
  * VPC Flow Logs

* Nắm được các kiến thức cơ bản về Amazon EC2, bao gồm:

  * Instance Types
  * Amazon Machine Images (AMI)
  * Amazon EBS
  * Key Pairs
  * Public và Private IP addresses
  * Vòng đời của EC2 instance

* Thực hành triển khai và quản lý Linux và Windows EC2 instance.

* Thực hành các phương thức kết nối tới EC2, bao gồm:

  * SSH sử dụng MobaXterm
  * RDP sử dụng Remote Desktop
  * EC2 Instance Connect
  * AWS Systems Manager Session Manager

* Tìm hiểu quy trình tạo và triển khai Custom AMI, cũng như vai trò của EC2Launch và Sysprep trong việc chuẩn bị Windows instance.

* Tìm hiểu các chức năng của AWS Systems Manager, bao gồm:

  * SSM Agent
  * Session Manager
  * Run Command
  * EC2Rescue for Windows

* Thực hành sử dụng EC2 User Data để cấu hình SSH public key trên Linux instance.

* Thực hành cấu hình PuTTY để xác thực bằng SSH key và quản lý các Saved Session.

* Có kinh nghiệm thực hành xử lý một số vấn đề thường gặp trên AWS, bao gồm:

  * SSH connection timeout
  * Lỗi cấu hình Security Group
  * SSH public key authentication failure
  * SSM Session Manager connectivity issues
  * Lỗi lấy Windows password từ Custom AMI

* Nắm được những khái niệm cơ bản về monitoring tài nguyên, quản lý tài nguyên và kiểm soát chi phí trên AWS.

* Ôn tập lộ trình AWS Cloud Journey và xác định các dịch vụ cũng như khái niệm kiến trúc phù hợp cho workshop/project trong thời gian thực tập.
