### Week 1 Objectives:

* Become familiar with the First Cloud AI Journey (FCAJ) learning environment and AWS learning roadmap.

* Understand the fundamentals of AWS, including core cloud service categories, account management, cost management, identity and access management, networking, and compute services.

* Gain hands-on experience with basic AWS services and cloud resource management.

* Develop fundamental skills in deploying, connecting to, and troubleshooting AWS resources.

* Review AWS services and concepts that will be used as a foundation for the upcoming internship workshop/project.

### Week 1 Achievements:

* Gained a foundational understanding of AWS and its main service categories.

* Became familiar with the AWS Management Console and the overall AWS learning roadmap.

* Learned the fundamentals of AWS account and cost management, including:

  * AWS Free Tier
  * AWS credits
  * AWS Budgets
  * Basic cost monitoring

* Learned the fundamentals of AWS Identity and Access Management (IAM), including:

  * IAM User
  * IAM Group
  * IAM Policy
  * IAM Role
  * Permission management
  * Role assumption
  * Switch Role

* Practiced creating IAM Users, Groups, Policies, and Roles.

* Learned the fundamental concepts of AWS networking, including:

  * Amazon VPC
  * Subnet
  * Route Table
  * Internet Gateway
  * NAT Gateway
  * Security Group
  * Network ACL
  * VPC Flow Logs

* Learned the fundamentals of Amazon EC2, including:

  * Instance Types
  * Amazon Machine Images (AMI)
  * Amazon EBS
  * Key Pairs
  * Public and Private IP addresses
  * EC2 instance lifecycle

* Successfully practiced deploying Linux and Windows EC2 instances.

* Practiced different EC2 access and connectivity methods, including:

  * SSH using MobaXterm
  * RDP using Remote Desktop
  * EC2 Instance Connect
  * AWS Systems Manager Session Manager

* Learned the process of creating and launching Custom AMIs and the role of EC2Launch and Sysprep when preparing Windows instances.

* Explored AWS Systems Manager capabilities, including:

  * SSM Agent
  * Session Manager
  * Run Command
  * EC2Rescue for Windows

* Practiced using EC2 User Data to configure SSH public keys on Linux instances.

* Practiced configuring PuTTY for SSH key-based authentication and managing saved SSH sessions.

* Gained practical experience troubleshooting AWS issues, including:

  * SSH connection timeouts
  * Security Group configuration issues
  * SSH public key authentication failures
  * SSM Session Manager connectivity issues
  * Windows password retrieval problems with Custom AMIs

* Gained an overview of AWS monitoring, resource management, and cost control practices.

* Reviewed the AWS Cloud Journey roadmap and identified AWS services and architectural concepts relevant to the upcoming internship workshop/project.
