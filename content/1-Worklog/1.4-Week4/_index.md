### Week 4 Objectives:

* Learn the core purposes and main capabilities of Amazon Cognito, AWS Amplify, and Amazon API Gateway.
* Understand how these services can support authentication, frontend development, and API communication in a web application.
* Identify how the three services could fit into the proposed project's AWS architecture.

* Gained an introductory understanding of Amazon Cognito and its role in user authentication.
* Learned about AWS Amplify and its potential use in developing and integrating the application's frontend with AWS services.
