This section records what I studied and practiced during the first five weeks of the First Cloud AI Journey program. It also shows how each week's learning connected to my AWS document management project.

**Week 1:** [AWS fundamentals, IAM, networking, and EC2](1.1-Week1/). I studied core AWS concepts, account and access management, VPC, and ways to launch and connect to EC2 instances.

**Week 2:** [Hands-on work with IAM roles, Cloud9, S3, and RDS](1.2-Week2/). I learned how to grant AWS permissions to applications securely, use the AWS CLI, store objects in S3, and connect an application to an RDS database.

**Week 3:** [Selecting the project and outlining its architecture](1.3-Week3/). I defined the direction for a document management system, considered suitable AWS services, and drafted its initial workflow.

**Week 4:** [Learning Cognito, Amplify, and API Gateway](1.4-Week4/). I focused on user authentication, frontend deployment, and connecting the interface to the backend through APIs.

**Week 5:** [Learning Lambda, S3, DynamoDB, IAM, and CloudWatch](1.5-Week5/). I studied backend processing, file and metadata storage, Lambda permissions, and monitoring logs and metrics.

I did not attend the company during the following weeks, so they are not included in this worklog.
